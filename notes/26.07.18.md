## 오늘 한 일

### 1. 어드민 setup 화면 보강 (`e3d4a6a`)
- 기존 포인트의 기준 사진·연결 미션·연결 재료를 생성 후에도 수정할 수 있게 함 (이전엔 등록 시점에만 가능)
- GPS가 애매한 상황을 위해 Kakao services로 주소→좌표 지오코딩 추가
- AI 판정 코멘트를 실패 시뿐 아니라 통과 시에도 참가자에게 보여주도록
- 이미 제출/도움요청이 달린 포인트를 삭제하면 FK 제약으로 죽던 버그 수정
- 기준/제출 사진을 object-cover에서 object-contain으로 바꿔 사진이 잘려 보이지 않게 함
- 모바일 브라우저 상단바가 접히면서 콘텐츠가 스크롤 없이 잘리는 문제 → `%` 대신 `dvh` 단위 사용
- 어드민 사진 업로드용 Server Action 본문 크기 제한을 10MB로 상향(기본 1MB로는 카메라 사진이 못 들어감)

### 2. 지도 마커 상태 표시 + 판정질문 사후 수정 (`64f94da`)
- 참가자 패널의 기준/제출 사진을 더 크게, 탭하면 전체화면으로 보이게 함
- 도움요청 버튼을 상단으로 옮겨 패널 콘텐츠를 안 가리게 함
- 지도 마커에 통과(초록 체크)/마감(회색 X) 상태를 클릭 없이 바로 표시 — 이전엔 마커 생성이 최초 1회만 실행되도록 막혀있어서 상태가 바뀌어도 마커가 다시 그려지지 않던 버그도 같이 고침
- 판정 질문(judgePrompt)을 포인트 생성 이후에도 미션/재료 수정 폼과 같이 고칠 수 있게 함

### 3. 팀/조 선택 잠금 기능 (`8112643`)
- `AppSettings` 싱글턴 모델 추가(`groupSelectionLocked` 플래그) + 어드민 토글(확인 대화상자 포함)
- 게임 시작 전까지는 자유롭게 팀/조를 다시 고를 수 있지만, 잠근 뒤에는 "다시 선택"이 숨겨지고 서버에서도 이미 선택한 그룹을 바꾸려는 시도를 조용히 막음(에러 대신 리다이렉트)
- 아직 그룹을 안 고른 기기는 잠금 이후에도 최초 선택은 가능 — 늦게 합류하는 참가자 대응
- 배경: 실제 게임 중에 팀 전환이 자유롭게 열려있으면 실수로/장난으로 중간에 팀을 바꿔버릴 위험이 있다는 우려
