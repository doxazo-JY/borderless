### 5. 어드민 미션 목록 natural sort (`0144284`)

시편 119편을 8절 단위로 8개 미션으로 나눠 등록했는데, 목록이 "1-24, 121-144, 145-160, ... 25-48, 49-72..." 순으로 뒤죽박죽 나오는 문제 발견. 원인은 `content` 문자열을 그대로 비교 정렬(`orderBy: content asc`)해서 "1"이 "12"보다 사전순으로 앞서는 것 — 생성 순서로 바꿔도 등록 순서 자체가 뒤섞여 있어서 해결이 안 됨을 먼저 확인. 문구에 담긴 숫자 부분만 실제 크기로 비교하는 natural sort 비교 함수를 만들어 JS에서 재정렬하는 방식으로 해결(타입 그룹 순서는 유지).

### 6. 저녁 — 어드민 사용성 다듬기 묶음 (아직 커밋 전, 이번에 같이 커밋)

- **미션 내용 여러 줄 입력**: 찬양 미션에 "어느 가사부터 어느 가사까지가 Bridge인지" 같은 부가 설명이 필요해져서, 미션 입력창을 `<textarea>`로 바꿔 Enter로 줄바꿈 가능하게 함. 어드민 목록/참가자 PASS 카드 둘 다 `whitespace-pre-line`으로 줄바꿈이 그대로 보이게 처리
- **주소 검색창에 현재 주소 자동 표시**: 포인트 위치 수정 화면에 좌표→주소 역지오코딩 결과를 보여주는 별도 영역을 처음 만들었다가, "굳이 따로 안 만들고 기존 '주소 검색' 입력창 자체에 현재 주소가 채워지게 하고, 다시 검색할 땐 지우고 입력하면 되지 않냐"는 피드백을 받아 단일 입력창으로 통합(새 포인트 등록 폼도 동일하게)
- **재료 이름 수정 기능**: "모둠어묵"→"모듬어묵" 같은 오타를 고치려는데 삭제/재생성만 가능했음 — `updateIngredient` 액션과 `IngredientEditor` 인라인 수정 컴포넌트 추가(연결된 포인트 유지된 채로 이름만 수정)
- **재료 목록 정렬 고정**: 재료 이름을 수정할 때마다 목록 순서가 흔들리는 문제 — `orderBy: { id: "asc" }` 추가로 생성 순서(면류→떡류→어묵류→기타) 고정. 카테고리 필드를 다시 넣을지 고민했으나, 재료가 16개뿐이라 정렬 고정만으로 충분하다고 판단해 카테고리는 보류
- **지역 경계선 표시**: 참가자 지도에 같은 지역 포인트들을 감싸는 경계선을 좌표 기반 자동 계산(convex hull + padding)으로 추가 — 마커 색을 지역별로 바꾸는 안도 검토했으나, 마커 색은 이미 통과/완료/마감 상태를 나타내는 용도라 지역 구분에 재사용하면 상태 정보를 잃게 돼서 기각. 대신 경계선만 추가하고, 지금 차례인 지역만 강조(처음엔 액센트 오렌지로 했다가 "마커의 '통과·완료대기' 상태색과 헷갈린다"는 피드백으로 마커 기본색과 같은 파랑으로 변경), 나머지 지역은 회색으로 옅게(피드백 받고 두께/불투명도 상향) 표시
- **펜션 패널 정리**: "모은 재료" 섹션의 "인벤토리 전체보기" 링크 제거 — 내용이 짧아서 굳이 별도 페이지로 안 보내도 된다는 판단
