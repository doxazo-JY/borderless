## 오늘 한 일

### 1. 문서 동기화 (`8d5c095`)
- CLAUDE.md 상태 문단에 퀴즈 미션 타입, 재료 모델 정리, 조원 이름 어드민 등록, 설정/팀 탭 분리 반영
- 기획서의 낡은 "10~20초" 영상 안내를 실제 기준인 30초 이상으로 수정

### 2. 방문포인트 이름 수정 기능 (`b0c527a`)
- `LocationDetailsEditor`의 인라인 수정 폼에 이름(name) 필드 추가 — 기존엔 기준사진/미션/재료/판정질문만 사후 수정 가능하고 이름은 등록 시점 고정이었음
- `updateLocationDetails` 액션에서 name도 같이 갱신하도록 확장

### 3. 기획서 8절 갱신 (`35ca242`)
- 재료 교환 규칙: 앱은 계속 관여하지 않되(범위 제외 유지), 실제 교환 장소는 미션 현장이 아니라 숙소 복귀 후 오프라인일 가능성이 높다는 예상 기록(미확정)
- 시간 부족으로 4개 지역을 다 못 도는 그룹: 별도 구제/강제완료 기능 없이 방문해서 실제로 받은 만큼만 받고 종료하는 것으로 확정
- 기본재료/부재료 구분: 프로그램상 구분 불필요 확정, 다만 "기본재료 사전 지급 + 부재료만 방문으로 획득" 게임 디자인이 논의 중이나 미확정이라는 상태 기록

### 4. 후보 방문포인트 사진 판정기준(judgePrompt) 초안 (커밋 없음)
- 사용자가 실내 사진(크림색 "Oh! happy day" 현수막, 파스텔 풍선 다발, 벽면 안내문, 분리수거함/쓰레기통, 소화기가 함께 보이는 구도)을 공유하며 판정 기준을 요청
- 기존 judgePrompt 3단 구조(장면 설명 → 랜드마크 4-5개 → "2개 이상 매치 시 통과" + 예외 규정)에 맞춰 초안 작성:
  1. "Oh! happy day" 필기체 문구가 적힌 현수막
  2. 현수막 위 파스텔톤 풍선 다발
  3. 현수막 우측 하단 노란색 원형 그래픽
  4. 벽면 안내문(컵 아이콘 + "화장실에 버려주세요")
  5. 안내문 아래 분리수거함("PAPER" 라벨) + 쓰레기통
- 풍선·현수막(1~3번)은 행사용 장식으로 보여 실제 미션 진행 시점엔 철거·교체될 위험이 있다는 점을 짚고, 이 포인트를 실제로 등록한다면 4~5번처럼 더 고정적인 요소 비중을 높이거나 답사 당일 장식이 그대로인지 재확인하라고 안내함. 실제 어드민 등록은 사용자가 직접 진행할 부분이라 코드/DB 변경 없음.
