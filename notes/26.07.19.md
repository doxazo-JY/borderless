# 데일리 노트 — 2026.07.19

## 오늘 요약 (공유용)

지도 마커 상태 표시를 통과/마감 2단계에서 3단계(미시도/통과·완료대기/완료)로 세분화했고, 나머지는 대부분 실기기로 써보면서 걸린 자잘한 버그들 — 새로고침하면 사라지던 실패 사유·사진, 업로드 용량 제한, 패널 상태가 다른 위치로 새는 문제, 확대 오버레이가 실기기에서 일부만 덮이는 문제 등을 하루 종일 잡았다.

## 오늘 한 일

### 1. 3단계 마커 범례 + 패널 여백 버그 (`c4c59a5`)
- 마커 상태를 미시도(파랑)/사진통과·영상대기(주황)/완료(초록)/마감(회색) 4색으로 구분
- 영상 업로드 탭에도 미션 안내를 같이 보여줘서, 뭘 찍어야 하는지 보려고 탭을 왔다갔다 안 해도 되게 함
- 마커 색 의미를 설명하는 토글형 범례("?") 버튼 추가 — "다음 목적지" 배지와 안 겹치도록 우하단에 배치
- 짧은 한 줄 안내(예: "이미 이 지역 다른 곳에서 통과함")에도 패널이 큰 최소 높이를 차지해서 아래에 빈 공간이 크게 남던 버그 수정

### 2. 제출 초기화 + 업로드 UX (`839b70a`)
- Supabase Storage 버킷 파일 크기 제한을 20MB→50MB로 상향(실제 폰 영상이 20MB를 넘어서 거부되는 사례 발생)
- 지급 확정 화면에 "초기화" 버튼 추가 — 관리자가 제출(사진/영상)을 지우고 캡을 되돌려서, DB를 직접 안 만져도 재시도시킬 수 있게 함
- 모든 사진/영상 입력에서 `capture="environment"`를 빼서, 매번 카메라가 강제로 열리지 않고 OS 기본 선택창(카메라/갤러리)이 뜨게 함
- 마커를 패널 안 닫고 바로 다른 마커로 옮겨 클릭하면 이전 위치에서 고른 파일 state가 남아있던 버그 — 위치 id를 key로 줘서 컴포넌트를 강제로 새로 마운트하도록 수정

### 3. AI 실패 사유 새로고침 후 유지 (`0dd2f7d`)
- 실패 메시지가 클라이언트 state에만 있어서 새로고침하면 사라짐(통과와 달리 DB에서 다시 계산 안 됨) — 그룹별 가장 최근 실패 제출을 map 페이지에서 같이 조회해서 초기 state를 채우도록 수정

### 4. 실패 사진도 유지 + 비교 레이아웃 (`01f9f9d`)
- 실패 응답에 photoUrl도 포함, map 페이지에서 실패 사진까지 같이 내려주도록 — 새로고침해도 거부된 사진이 텍스트 사유만이 아니라 사진까지 남아있게 됨
- 제출 전 화면에서도 기준/업로드 사진을 통과 화면과 같은 2열 비교 레이아웃으로 통일
- 사진 확대 오버레이의 닫기 버튼을 우상단→하단 중앙으로 이동 — 실기기에서 노치/브라우저 UI에 가려지는 문제(데스크톱 반응형 테스트에선 안 보였던 문제)

### 5. 사진 확대 오버레이를 body로 포탈 (`afe5093`)
- 오버레이가 패널의 `overflow-y-auto` 스크롤 컨테이너 자손이라, `position: fixed`인데도 실기기 모바일 사파리에서 그 스크롤 영역 안에서만 "고정"되는 문제 발생(데스크톱에서는 재현 안 됨) — `createPortal`로 `document.body`에 직접 띄우도록 수정
