# 데일리 노트 — 2026.07.21

> 이 노트는 라이브 세션 기록이 아니라, 나중에(2026-07-27) 커밋 로그를 근거로 소급 작성한 것이다.

## 오늘 요약 (공유용)

기능적으로 가장 큰 하루 — 재료 모델을 정리하고, 미션 타입을 3개에서 4개(퀴즈 추가)로 늘렸고, 어드민의 흩어져있던 운영 화면(지급확정/대시보드/영상 모아보기)을 대시보드 하나로 합쳤다. 도움 요청에 조원 이름과 메시지를 남기게 했고, 지도 마커 선택 표시와 어드민 목록 레이아웃도 여러 차례 다듬었다.

## 오늘 한 일

### 1. 재료 모델 단순화 + 퀴즈 타입 + 어드민 운영화면 통합 (`0c7863b`)
- `Ingredient`에서 `category`/`variant`/`isBase` 제거 — 아무 로직도 안 읽던 표시 전용 필드였음. `name`에 전체 라벨을 직접 담는 방식으로 전환(예: "떡(치즈떡)"), 마이그레이션으로 기존 variant 텍스트를 name에 합침
- 4번째 미션 타입 **퀴즈(PUZZLE)** 추가 — 영상 업로드 대신 텍스트 정답 제출로 완료, 공백/대소문자 무시하고 쉼표로 여러 정답 허용. 미션에 선택적 이미지(`Mission.imageUrl`)도 추가해서 PASS 카드에 같이 보여줌
- 지급확정/대시보드/제출영상 3개로 나뉘어 있던 어드민 페이지를 대시보드 하나로 통합 — 포인트별 카드에 통과자·제출사진·영상(또는 퀴즈 정답)·지급확정/초기화 버튼을 한 번에
- 리허설 테스트 제출을 한 번에 정리하는 "전체 초기화" 버튼(확인 대화상자 포함) 추가
- 어드민 화면 폭을 `max-w-7xl`로 넓히고 목록을 반응형 그리드로 전환, 상단 네비게이션 sticky 처리
- 지도 마커에 지역 알파벳(A/B/C/D) 접두사 표시 + 선택 시 확대/진하게 — 같은 좌표에 겹친 마커도 구분되게
- 미션/포인트 목록을 타입/활성여부 기준으로 정렬해서 수정할 때마다 순서가 안 흔들리게 함(※ 이후 7/27에 자연스러운 숫자 정렬(natural sort) 문제로 다시 손보게 됨)

### 2. 도움 요청 이름/메시지 + 지도·어드민 다듬기 (`3c1e653`)
- 도움 요청 버튼을 누르면 메시지 입력창이 펼쳐지도록 하고, 팀/조 선택 화면에서 조원 2명 이름을 필수로 받아 쿠키에 저장 → 도움 요청마다 `requesterName`으로 스냅샷 — 임원이 누구를 찾아야 하는지 알 수 있게
- `HelpButton`이 4xx/5xx 응답에도 "전송됨"으로 표시하던 버그 수정(`fetch`는 에러 상태코드에서 throw 안 함)
- 지도 마커 선택 표시를 확대+마커 자체 상태색을 진하게 하는 방식으로 변경(기존 오렌지 링 버전은 색이 어울리지 않아 교체), 범례도 실제 핀 모양을 그대로 축소해서 보여주도록
- 어드민 목록/그리드를 고정 컬럼 수 대신 auto-fit minmax 트랙으로 전환 — 개수가 애매하면 마지막 줄이 혼자 좁은 칸에 남던 문제(도움요청/대시보드/setup 페이지 공통) 해결
- 대시보드 "전체 초기화"가 HelpRequest도 같이 지우도록 확장(참가자 기기 쿠키는 여전히 못 지움 — 확인 문구에 명시)

### 3. 지도/어드민 폴리시 + 잠금 상태 홈 리다이렉트 (`0fa15e5`)
- 지금 갈 수 없는 지역(차례 아님/이미 다른 포인트로 채워진 지역)의 마커를 새 색 없이 투명도만 낮춰서 흐리게 — 지금 차례인 지역의 열린 포인트가 상대적으로 도드라지게
- 어드민 페이지 폭을 `max-w-7xl`(가운데 정렬, 넓은 모니터에서 여백 낭비) → `max-w-[1600px]`로 재조정, 카드 텍스트 줄바꿈을 `break-keep`으로 통일, 액션 링크를 제목 옆 대신 카드 하단 별도 줄로 이동
- 이미 팀/조를 선택하고 잠긴 기기가 "/"에 다시 들어오면 곧장 `/map`으로 리다이렉트하도록(뒤로가기로 선택 화면에 다시 진입하는 것 방지)
